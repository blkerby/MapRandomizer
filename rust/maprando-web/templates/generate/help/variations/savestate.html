Save states

This option allows creating at most one save state at a time. A save state can be loaded an unlimited amount of times. Any save state is cleared automatically by a regular save (at a save station or the Ship).

When set to "Unlimited", a save state can be created at any time.

When set to "Limited", a save state can be created only once, until refreshed by a regular save or load.

This feature requires 256KB SRAM; FXPAK and most modern emulators support this configuration.
