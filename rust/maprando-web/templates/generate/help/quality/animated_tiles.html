Animated map tiles

If enabled, the pause map displays a tile containing two items by alternating between the two tile shapes; it also applies when a tile contains both an item and an objective marker. The minimap is unaffected. This setting affects the following rooms:

  • Billy Mays Room
  • Brinstar Reserve Tank Room
  • Green Pirates Shaft
  • Norfair Reserve Tank Room
  • Watering Hole
  • West Sand Pit
  • Bomb Torizo Room (if it is an objective)
