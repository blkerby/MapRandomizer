Animated Map Tiles

If enabled, rooms that contain two items in the same map tile will alternate between the items tile types when they are of a different item class (depending on QOL settings). For example, with 3 or 4 tier items, a Major Item and Energy Tank in the same tile would alternate between a hollow circle and a solid circle. This setting affects the following rooms:

  • Billy Mays
  • Green Brinstar Reserve
  • Green Pirates Shaft
  • Norfair Reserve
  • Watering Hole
  • West Sand Pit
  • Bomb Torizo (If it is an objective)
